Ferry

A Kubernetes-native L7 load balancer and API gateway, written in Rust. This page is served through Ferry, and every button below sends real requests through it to mock backends running in the same container.

This is a demo on Render's free tier: one small container, three mock backends, a fixed config. It is not a production deployment. Requests are rate-limited to 50/s across everyone, so you may see a 429.

Round robin

GET /hello goes to a cluster of two backends. Ferry alternates between them.

Canary split

GET /canary is weighted 90/10 between backend a and backend b.

Header match

The same path with x-canary: always matches a more specific rule that always picks b.

Retries

GET /retry hits a backend that fails half the time. Ferry retries 503s up to twice, so about 7 in 8 requests still succeed.

No route

GET /nope matches no route, so Ferry answers 404 itself.

WebSocket

Ferry upgrades /ws and tunnels the connection to an echo backend.
